# Composition Templates · C1-C9 Prompt 骨架（Stage 1B 必读）

> **核心目的**：把 9 个组合各封装成 1 个 fill-in-blank 模板。Codex 推理段 **只填空，不自由发挥**。
> 这是「生图准确性」的关键保障——避免每次现编漏写反向闸、icon 位置描述、透视句式。

## 通用结构（所有模板共享）

每个模板由 6 段组成，**按固定顺序拼接**：

```
[1 主体段] + [2 副体关系段] + [3 icon 段] + [4 装饰段] + [5 透视段] + [6 反向闸段]
```

| 段 | 必填 | 内容 |
| --- | --- | --- |
| 1 主体段 | ✓ | `1 个 [A 主体]，[主体姿态动感词]` |
| 2 副体关系段 | C 编号决定 | 描述 A 和 B 的关系动作（装/出入/递/承载/重叠） |
| 3 icon 段 | ✓ | `1 个面性 [icon 名] icon（[B1/B2/B4 位置词]）` |
| 4 装饰段 | ✓ | `[N] 颗/朵/段/团 [装饰类] 散落，[动势]` |
| 5 透视段 | ✓ | `[正面 / 俯视 X° / 仰视 X° / 侧 X° / 3/4 视角]` |
| 6 反向闸段 | ✓ | `[A]/[B] 表面无任何卡通图案/贴纸/插画/文字装饰，仅允许 1 个面性 X icon` |

## 模板 C1：A1 容器 + B1 表面（A 装 B，A 表面贴 icon）

**适用**：礼盒里装着小物 / 信封装贺卡 / 购物袋装商品

```
[中文]
1 个 [A 容器]（如礼盒/宝箱/购物袋/钱包/信封），[容器姿态：刚被打开/倾斜悬浮/盖子飞起]，
内部放着 1 个 [B 副物]（如 1 张卡/1 本书/1 件商品/1 张钞票），
1 个面性 [icon 名] icon 贴在 [A] 侧面正中（与表面共平面，微凸起）；
[N] 颗 [装饰类] 散落（如 4 颗小星星 / 4 朵小爱心 / 4 段小彩带），[动势：向中心收敛 / 从中心扩散 / 跟随主体动势]；
[透视：3/4 视角微仰 15° / 俯视 30° / 正面微仰 10°]；
[A] 和 [B] 表面无任何卡通图案/贴纸/插画/文字装饰，仅允许 1 个面性 [icon 名] icon。

[English]
1 [A container] (e.g. gift box / treasure chest / shopping bag / wallet / envelope), [container motion],
inside there is 1 [B item] (e.g. 1 card / 1 book / 1 product / 1 banknote),
1 filled [icon name] icon attached to the side center of [A] (coplanar with surface, slightly raised);
[N] [decoration type] scattered (e.g. 4 small twinkling stars), [motion];
[perspective: 3/4 view slightly tilted up 15° / top-down 30° / front slightly tilted up 10°];
[A] and [B] surfaces have no cartoon patterns / stickers / illustrations / text decorations, only 1 filled [icon name] icon allowed.
```

## 5 套方案填空总流程

1. Stage 0.5 内部底稿先确定每套方向的 C 编号
2. Stage 1B 时 **5 套 prompt 各按对应模板填空**：
   - 把方括号 `[A 容器]` 替换成具体元素（如"礼盒"）
   - 把方括号 `[icon 名]` 替换成 element-library.md 里挑的具体 icon
   - 把方括号 `[N] [装饰类]` 替换成具体数量+装饰名（如"4 颗小星星"）
   - 把方括号 `[透视]` 替换成 5 套至少覆盖 3 种的具体视角
3. 5 套之间装饰类型不重复、透视至少 3 种不同（这两条 agent 内部自检）

## 反向闸段为何写成 `仅允许 1 个面性 X icon`

如果只写"表面无任何卡通图案/贴纸/插画/文字装饰"，模型可能把刚才声明的 icon 也当成"装饰"擦掉。

**显式写"仅允许 1 个面性 X icon"是给模型一个例外白名单**，让它知道"icon 不在禁止之列"。

这是 v6 实测踩过 30+ 张图才总结出的经验，**所有 9 个模板都必须保留这一句**。

## 模板使用反例

```
❌ 自由发挥（违反模板顺序，漏反向闸）：
   礼盒装着日历，旁边有彩带和星星，氛围温馨
   ↑ 没说 icon / 没说透视 / 没说反向闸 / 装饰是混搭的

❌ 关键参数留空：
   1 个 [A 容器]，内部放着 1 个 [B 副物]……
   ↑ 必须真的填具体词，模板的方括号是占位符不是字面内容

✅ 正确填空：
   1 个橙金色礼盒，刚被打开盖子微微飞起，内部放着 1 张白色立体日历卡，
   1 个面性分享箭头 icon 贴在礼盒侧面正中（与表面共平面，微凸起）；
   4 颗小星星散落，从礼盒爆开向外扩散；
   3/4 视角微仰 15°；
   礼盒和日历卡表面无任何卡通图案/贴纸/插画/文字装饰，仅允许 1 个面性分享箭头 icon。
```
